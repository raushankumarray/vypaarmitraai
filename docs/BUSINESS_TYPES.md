**VypaarMitra AI • NPB MEDIA**

## 1. Engine Overview
VypaarMitra AI avoids hard-coding product schemas. Instead, it utilizes a configurable **Business Type Engine** that defines:
- Industry Category
- Default Modules
- Default Categories & Units
- Default GST Tax Rate
- Dynamic Custom Fields

## 3. Dynamic Custom Fields Examples
- **Cloth Store**: Size, Color, Fabric, Gender Target, Season, Pattern.
- **Kirana**: Net Weight, Unit, Pack Size, Batch No, Expiry Date.
- **Medical / Pharmacy**: Generic Salt Name, Manufacturer, Batch No, Expiry Date, Prescription Required (Rx), Schedule H Drug.
- **Mobile Shop**: IMEI 1, IMEI 2, RAM/ROM, Color, Warranty Months.
- **Jewellery**: Karat Purity, Gross Weight, Net Weight, Making Charge, HUID Hallmark No.
