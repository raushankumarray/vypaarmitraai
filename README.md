## Overview
VypaarMitra AI is an enterprise multi-tenant SaaS platform tailored for retail, supermarkets, medical/pharmacy, garments, and software/services businesses across India.

### Key Capabilities
- **Multi-Tenant SaaS Architecture**: Strict tenant isolation across merchants, outlets, cashiers, and managers.
- **Dual Cloud Database Engine**: Simultaneous parallel real-time sync across **Firebase Realtime Database** and **Google Cloud Firestore**.
- **POS Smart Billing & Tax Invoicing**: Rapid barcode scanning, thermal receipt printing (58mm/80mm), and professional GST-compliant A4 smart invoices with dynamic UPI QR code generator.
- **Sundry Khatabook**: Full ledger accounting for customer credit dues, payment collections, and WhatsApp reminder sharing.
- **Inventory & Batch Tracking**: Strict batch, expiry, MRP, and stock movement tracking with low-stock alerts.
- **AI Business Copilot**: Hindi and English natural language assistant for instant sales, dues, profit, and stock valuation insights.
- **Support Desk**: Direct 24/7 helpline (+91 8877300114), WhatsApp integration, and live ticketing desk.

## Getting Started

### Prerequisites
- Node.js 18+
- npm / yarn / pnpm

### Installation
```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev

# 3. Build for production
npm run build

# 4. Start production server
npm run start
```
